# MaidMatch AI

MaidMatch AI is a modern React.js web application designed to connect users with trusted domestic helpers, cleaners, caregivers, and home service professionals through an AI-powered matching system.

## 🌐 Live Website

https://maidmatch.ai/

---

## 🚀 Features

- AI-powered helper matching
- User authentication & authorization
- Search and filter domestic helpers
- Real-time profile management
- Responsive modern UI
- Secure API integration
- Booking & communication system
- Ratings and reviews
- Mobile-friendly experience

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Axios
- Redux / Context API
- Tailwind CSS / Bootstrap
- Firebase / JWT Authentication

### Backend
- Node.js
- Express.js
- MongoDB / Firebase

### Deployment
- Vercel / Netlify / AWS
